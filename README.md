A single-line cat joke with a setup and a turn that lands: a cat who treats knocking your glass off the table like a hard day's work — and clocks out immediately after.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/catjoke-test node main.ts
cat /tmp/catjoke-test/entry.txt
```

The program writes exactly one line (1–200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node-stdlib-only, no network, no dependencies.
